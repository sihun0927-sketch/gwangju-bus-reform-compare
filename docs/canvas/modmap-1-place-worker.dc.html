compare

GET /compare?from=&to=

  • 좌표 둘
  • 번들: stops · routes · route_stops
  • 번들: transfers · route_links

개편 전 카드 + 개편 후 카드 조각 (머리에 상태)
경로 지도 좌표 JSON (조각 안)
다른 경로 카드용 경로 키

안이 다섯이다 — network(번들을 노선망 둘로) → candidates(도보권 후보) → search(직행 · 환승 1~2회) → rank(추정 소요 시간 → 환승 → 도보) → render. 노선망 각각 한 번. 두 지점이 500m 이하면 「걸어갈 수 있는 거리」. 상태는 카드 머리에 서고 판정 문장은 없다(§7 Q11)

요청당 CPU 중앙값 20~21ms · p90 32ms — 무료 요금제 상한 10ms를 넘는다. 80%가 walkableStops와 갈아탄다다(§6-4 · §8)

Worker

journey

GET /journey/{경로 키}

  • 경로 키 (노선망 · 두 지점 · 구간마다 노선과 정류장)
  • 번들: stops · route_stops

다른 경로 카드 조각
(정류장 목록 · 지표 · 좌표 JSON)

compare가 찾은 경로 하나를 다시 그린다. 탐색을 다시 하지 않는다 — 구간마다 방향·순번만 고른다. 저장소가 없어 키만으로 열리고, 번들과 안 맞으면 404와 한 줄 문구
